# vks-weekly-dashboard

Публичная GitHub Pages страница для еженедельного ВКС.

- `index.html` — интерфейс страницы
- `data/documents.json` — данные для еженедельного обновления

Обновлять сотрудникам нужно только содержимое документов в облаке и, при необходимости, строки в `data/documents.json` ответственным лицом.
