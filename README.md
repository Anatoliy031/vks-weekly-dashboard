# VKS Pages

Готовый набор файлов для GitHub Pages, который читает данные из Google Sheets.

## Структура

- `index.html` — интерфейс страницы
- `data/documents.json` — старый пример данных, можно оставить как резерв

## Главная логика

Сотрудники не трогают GitHub, HTML или JSON.
Они правят только одну общую Google-таблицу.

Сайт читает опубликованный CSV этой таблицы.

## Как настроить

1. Создай Google-таблицу и импортируй `VKS_google_sheet_template.csv`
2. Заполни строки по ответственным
3. В Google Sheets выбери:
   - `Файл` → `Опубликовать в интернете`
   - опубликуй нужный лист в формате `CSV`
4. Скопируй ссылку вида:
   - `https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/gviz/tq?tqx=out:csv&sheet=Лист1`
5. В файле `index.html` подставь эту ссылку в переменную:
   - `GOOGLE_SHEET_CSV_URL`
6. Закоммить и обнови GitHub Pages репозиторий

## Какие колонки должны быть в таблице

- `Блок`
- `Название материала`
- `Статус`
- `Ответственный`
- `Дата обновления`
- `Хранилище`
- `Краткое описание`
- `Комментарий недели`
- `Тезис 1`
- `Тезис 2`
- `Тезис 3`
- `Основная ссылка`
- `Резервная ссылка`
- `Порядок сортировки`
- `Показывать блок`

## Какие статусы понимает сайт

- `Обновлено`
- `Требует внимания`
- `Критично`
- `Без статуса`

Сайт сам окрасит карточки в нужный цвет.

## Важно

Лучше использовать постоянные облачные ссылки, чтобы сотрудники обновляли содержимое документов, а не меняли URL каждую неделю.
